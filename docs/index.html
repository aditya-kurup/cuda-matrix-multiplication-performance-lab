03 / INTERPRETATION

What the experiment shows

01

Naive

One thread computes one C element. It walks K and reads one A value and one B value per multiply. Neighboring outputs may request the same values from global memory.

02

Tiled

A 16 × 16 block cooperatively loads A and B tiles into shared memory. Threads reuse those values for a K segment, with barriers before use and before overwriting the tiles.

03

Trust

Both outputs are checked against a deterministic CPU reference that accumulates in double precision. Every element must meet an FP32 mixed absolute/relative tolerance, including boundary tiles.

Reading the numbers

Small shapes can be dominated by launch and measurement overhead. Larger shapes offer more opportunities for tile reuse, but the observed winner depends on the GPU and matrix shape. CUDA-event timings alone do not identify cache behavior, occupancy, or a hardware bottleneck; optional Nsight Compute profiling can investigate those separately.
